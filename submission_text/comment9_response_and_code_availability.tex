\noindent\textbf{Response to Comment 9.}

We thank the reviewer for emphasizing reproducibility. We have reorganized
and expanded the public repository so that the external-validation and
failure-analysis results reported in the manuscript can be traced directly
to the corresponding source code and canonical outputs.

In particular, we added a standalone deterministic script for reconstructing
the leakage-controlled external cohort. The script normalizes the
BreastDCEDL/I-SPY2 and MAMA-MIA patient identifiers, compares the two
rosters, and excludes the 980 matched MAMA-MIA I-SPY2-source cases before
external evaluation, leaving the 526-case external cohort used in the
manuscript (Duke, $n=291$; I-SPY1, $n=171$; NACT-Pilot, $n=64$). The
repository also identifies the scripts used for phase selection and
preprocessing, external evaluation, LCC postprocessing, failure attribution,
and the final canonical LCC-collapse audit.

To improve traceability, we added a manuscript-to-results map linking the
principal reported numerical results to the corresponding scripts and output
files, together with lightweight verification scripts that check the cohort
construction, principal external Dice values, and canonical LCC-collapse
results. Earlier exploratory audit outputs are retained for provenance but
are explicitly marked as superseded where they differ from the canonical
analysis used in the revised manuscript.

Finally, we updated the Code Availability statement to provide the public
repository and the exact commit identifier corresponding to the revised
manuscript. Imaging data themselves are not redistributed; the repository
instead provides data-access instructions for obtaining the original public
datasets under their respective access conditions.
