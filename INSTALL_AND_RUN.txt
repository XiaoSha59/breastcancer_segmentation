=========================

IMPORTANT SECURITY ACTION — DO THIS FIRST
-----------------------------------------
The currently public download_mama_mia.py contains a Synapse personal access
token. Revoke that token in Synapse before doing anything else. Replacing the
file in GitHub does not revoke the old credential.

After revoking it, this pack replaces download_mama_mia.py with a version that
reads SYNAPSE_AUTH_TOKEN from an environment variable.

RUN BEFORE COMMITTING
---------------------

Open a terminal in the repository root.

1) Install lightweight requirements:

   python -m pip install -r reproducibility/requirements.txt

2) Reconstruct and audit cohort overlap:

   python reproducibility/build_external_cohort.py

Expected ending:

   ALL COHORT-CONSTRUCTION CHECKS PASSED

3) Verify manuscript numbers:

   python reproducibility/verify_paper_numbers.py

Expected ending:

   ALL CHECKS PASSED

If either script prints FAIL, do NOT commit yet. Investigate the mismatch.

COMMIT TO MAIN
--------------

Your repository's default branch is "main". A release/tag is not necessary.
One ordinary commit to main is fine.

Example:

   git status
   git add README.md MANUSCRIPT_NUMBERS.md download_mama_mia.py reproducibility \
       15_final_lcc_collapse_profile/article_takeaways_15.txt
   git commit -m "Improve reproducibility and canonical audit traceability"
   git push origin main

Then get the exact commit SHA:

   git rev-parse HEAD

Copy that SHA into the manuscript Code Availability statement where the
submission text currently says:

   <COMMIT-SHA>

WHY THE SHA MATTERS
-------------------
A commit SHA is enough to freeze the exact repository state used for the
revision. You do not need a GitHub Release if you do not want one.
